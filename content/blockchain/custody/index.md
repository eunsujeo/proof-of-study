이 챕터는 입문 개념 설명이 아닙니다.

목표는 프로덕션 환경에서 수탁형 지갑 인프라를 어떻게 설계할지 판단할 준비를 하는 것입니다.

Fireblocks를 사용할 수도 있지만, Fireblocks에 고정하지 않습니다.

BitGo, Circle 같은 provider를 비교하고, 필요하면 자체 signer 구조도 검토합니다.

학습 흐름은 아래 순서로 진행합니다.

```text
리서치
-> 전체 아키텍처
-> 입금과 sweep
-> 출금 흐름
-> EVM nonce 관리
-> gas와 유동성
-> 프로덕션 인프라 체크리스트
```

이 챕터에서 계속 붙잡을 질문은 하나입니다.

```text
동시 출금이 많아지는 프로덕션 환경에서
자산을 안전하게 지키면서
출금 지연과 nonce 병목을 어떻게 줄일 것인가?
```
